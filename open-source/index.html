MAINTAINER WORK

Open source, with proper credit.

Original code, forks, upstream contributions, maintenance, pull requests and issue triage are different forms of engineering work. Each deserves accurate attribution.

Original work and maintained repositories

OpenXdrive (organization repository) is an example of a public codebase associated with this Labs ecosystem. FinCo-Pilot is tracked under its own account. Source ownership and maintainer rights are verified per repository, never inferred from a brand label.

Forks and upstream work

The UNILOOP organization fork links to the upstream project. A fork alone is not proof that an upstream pull request was accepted. Future contribution profiles will cite the exact upstream PR, review result and merge commit when available.

How to collaborate

Read our contribution guide to understand issue selection, reproducible testing, security reporting and review etiquette. Project-specific repositories control their own CI and branch rules. This website is an index, not a substitute for those repositories.

Contribution record policy

Future entries will record repository, task, issue/PR URL, role (author, reviewer or maintainer), status and verified outcome. Only public, linkable work will be displayed. Never claim a merge, maintainer role or endorsement unless evidence exists.
