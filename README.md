# Satzzxzxx Labs — Website V1

Responsive static website prototype. Inspired by Octane's information architecture, with original content and styling.

## Run locally

```sh
python3 -m http.server 8000
```

Visit http://localhost:8000.

## Pages
- Home: work, open source, studio, journal, community, contact
- Journal: searchable article drafts categorized by topic

## Publishing
All existing articles are starter drafts, not verified reporting. For production, add real citations, editor review, metadata, domain and sitemap. Future CMS integration is pending.
