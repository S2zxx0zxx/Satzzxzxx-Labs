# Contributing to Satzzxzxx Labs

Satzzxzxx Labs is an independent technology studio and open-source initiative. Project repositories keep their own licenses, ownership and security requirements.

## Before a proposal
1. Select the correct repository: products and upstream projects are linked in `data/catalog.json`.
2. Open a narrowly scoped public issue using a reproducible problem, expected outcome, links and any non-sensitive logs.
3. Do not claim upstream PR merges or organizational affiliation without evidence.
4. For changes to this website, create a feature branch, preserve `assets/style.css` and visual structure unless a UI change has been separately approved, and run `python3 scripts/verify_site.py`.
5. Test all changed URLs, mobile navigation and keyboard focus. PRs must have a clear description, screenshots when visuals actually change, and a link to appropriate testing evidence.

## Content submissions
- Technical articles need a real implementation or experiment, date, sources, limitations and accurate attribution.
- Application reviews need first-hand testing and explicit conflicts of interest. No fabricated ratings, fake scam accusations, scraped personal data, or affiliate links without disclosure.
- The editorial policy is in `docs/EDITORIAL_POLICY.md`.
- Drafts remain noindex and absent from the sitemap. Article catalog records must be updated as part of publication.

## Responsible communication
Public GitHub issues are not confidential. Do not send secrets, financial records, unreleased vulnerabilities, personal contact information or user data. Follow `SECURITY.md` for private reporting where supported.

Maintainers reserve the right to request clearer evidence, reject unsafe changes, or close spam and abusive discussions. Review is not a promise of acceptance.
