CONTACT & COLLABORATION

Let's work on useful things.

This is a small independent studio initiative. The safest current contact route is a tracked GitHub discussion through an issue, with no confidential or personal financial information posted publicly.

Product support

Use FinCo-Pilot support for FinCo-Pilot-specific questions, not this site's public issue tracker. Follow each other product's own support and repository process.

Open-source and collaboration requests

For public technical proposals, project links and collaboration ideas, open a collaboration request on GitHub. GitHub sign-in is required and the issue is publicly visible. Read the contribution policy before proposing code changes.

Privacy and security

Do not post passwords, private API keys, financial records, identity documents, personal contact details, unreleased code, or vulnerability exploitation steps in public issues. Sensitive vulnerabilities belong in the affected repository's enabled private security reporting channel; if none is available, do not publish the details.

Editorial feedback and corrections

Include the exact article URL, quoted assertion, a source that supports the correction and the observed date. Good-faith corrections will be reviewed for evidence and reflected in the relevant article when substantiated.
