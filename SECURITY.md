# Security reporting

Do **not** post vulnerabilities, exploit details, credentials, tokens, private financial records, or user information in public issues, pull requests or discussions.

For a security concern in FinCo-Pilot, UNILOOP or OpenXdrive, use that **affected repository's own** security policy and GitHub private vulnerability reporting channel if enabled. This Labs documentation site is not a replacement for the product security intake.

For this website, use the GitHub repository's private vulnerability reporting option under Security if enabled. If unavailable, withhold exploit details until a verified private contact method is established. Do not assume a public issue is confidential.

No vulnerability response SLA or certification is claimed.
